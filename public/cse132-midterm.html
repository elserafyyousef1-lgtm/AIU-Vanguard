QUESTION 01

Write the equation of Y

CMOS · combinational
Question 1 — exam paper · نفس ورقة الدكتور بالظبط
الحل · Solution
1

Recall the one rule. A PMOS transistor conducts when its gate = 0; an NMOS conducts when its gate = 1. The pull-up network (to VDD) drives Y = 1; the pull-down network (to GND) drives Y = 0. They are duals — exactly one conducts at a time.

2

Read the pull-down — it is the easy one. The NMOS network connects Y to GND (making Y = 0) when: A and B are both on (series path) or C is on (the parallel branch).

pull-down conducts  ⟺  (A · B) + C  =  1  →  Y = 0
3

Invert to get Y. Y is high whenever the pull-down is off, so Y is the complement of that expression:

Y = (A · B + C)′  =  A · B + C

This is an AND-OR-INVERT (AOI) gate — AND the pair A·B, OR in C, then invert.

4

Cross-check with the pull-up. By De Morgan, (A·B + C)′ = (A·B)·C = (A + B)·C. The pull-up conducts when (A = 0 or B = 0) and C = 0 — exactly A ∥ B in series with C. ✓ The schematic and the equation agree.

Final answer · the equation of Y
Y = (A · B + C)′   — an AND-OR-INVERT gate

Completed truth table

Transistor state: Px = ON when x = 0 · Nx = ON when x = 1. Then Y = (A·B + C)′.

الفكرة. شبكة الـ NMOS بتوصّل الخرج بالأرض (0)، والـ PMOS بتوصّله بالـ VDD (1)، وهما دايمًا عكس بعض. فأسهل حاجة تقرأ إمتى الخرج = 0 من شبكة الـ NMOS: لما (A و B شغّالين) أو (C شغّال) → يبقى Y = 0. اعكسها تطلع المعادلة على طول: Y = (A·B + C)′.

QUESTION 02

Parallelism — the coffee shop

performance · pipelining
Question 2 — exam paper · نفس ورقة الدكتور بالظبط
الحل · Solution

First, two definitions to keep straight

L

Latency — the time for one cup to travel start → finish.

T

Throughput — how many cups finish per unit time. Latency is about one token; throughput is about the flow.

(a) Latency of one cup

One cup must pass through both stages in order: prepare (5), then the machine (10).

Latency = 5 + 10 = 15 min per cup

With no parallelism you also start the next cup only after this one is done, so the baseline throughput is

1 cup / 15 min = 60 / 15 = 4 cups / hour
(a) Latency
15 minutes per cup  (baseline throughput 4 cups/hr)

(b) Spatial parallelism — replicate the hardware

Spatial = put down copies of the whole station side by side; they work at the same time. With N full stations, N cups finish every 15 minutes. Taking N = 2 (two preppers + two machines):

throughput = 2 cups / 15 min = 8 cups / hour   (general: N / 15 min)

Latency of a single cup is unchanged — still 15 min. You bought quantity, not speed.

(b) Spatial (×2)
8 cups / hour

(c) Temporal parallelism — pipelining

Temporal = keep one set of hardware but overlap the stages, like an assembly line: while cup #1 is inside the machine, start preparing cup #2. In steady state a cup comes out every bottleneck stage — the slowest stage — which is the machine at 10 min.

steady-state throughput = 1 cup / max(5, 10) min = 1 / 10 min = 6 cups / hour

The first cup still takes the full 15 min (latency doesn’t improve); after that one exits every 10 min.

(c) Temporal (pipeline)
6 cups / hour  (bottleneck = 10 min stage)

(d) Both — pipeline and replicate

Run two pipelined lines at once. Each emits one cup per 10 min, so together:

throughput = 2 cups / 10 min = 1 cup / 5 min = 12 cups / hour   (general: N / 10 min)
(d) Both (×2 pipeline)
12 cups / hour

All four at a glance

TechniqueLatency (1 cup)Throughput
None (sequential)15 min4 / hr
Spatial  (×2 stations)15 min8 / hr
Temporal (pipeline)15 min first, 10 min steady6 / hr
Both  (×2 pipelines)15 min12 / hr
Assumption: “spatial / both” duplicate the hardware ×2 (the general formulas in N are shown above). If the paper fixes a different number of copies, plug it into N.
الفكرة. الـ latency بتاعت الكوب الواحد ثابتة = 15 دقيقة في كل الحالات. اللي بيتحسّن هو الـ throughput: spatial = نكرّر الأجهزة (كمية أكبر بنفس السرعة)، وtemporal = خط إنتاج بيتحدّد بأبطأ مرحلة (10 دقايق)، وboth = الاتنين مع بعض.

QUESTION 03

Compute 14 / 7 and fill the table

arithmetic · division
Question 3 — exam paper · نفس ورقة الدكتور بالظبط
الحل · Solution

Set-up

Work in 4 bits. Dividend A = 14 = 1110₂, divisor B = 7 = 0111₂. Build the quotient Q one bit per iteration, MSB→LSB (4 iterations), tracking the running remainder R′ (start R′ = 0).

The doctor's algorithm — the “4×4 Divider” slide, exactly

R′ = 0
for i = N−1 down to 0:
   R = { R′ << 1 , Ai }
   D = R − B
   if D < 0 → Qi = 0 , R′ = R
   else    → Qi = 1 , R′ = D
1

Shift. Shift the running remainder left and pull in the next dividend bit: R = { R′ << 1 , Ai }.

2

Subtract the divisor. D = R − B  (with B = 7). Note the doctor’s convention: the D column is the difference R − B — not the divisor.

3

Decide. If D < 0 the divisor didn’t fit → Qi = 0 and restore R′ = R. If D ≥ 0 it fit → Qi = 1 and R′ = D.

iAiR = {R′≪1, Ai} D = R − BQiR′
310001 (1)1 − 7 = −6 < 000001 (1)
210011 (3)3 − 7 = −4 < 000011 (3)
110111 (7)7 − 7 = 0 ≥ 010000 (0)
000000 (0)0 − 7 = −7 < 000000 (0)
B = 0111₂ = 7 (divisor, given). D is the trial difference R − B; R′ is the remainder carried into the next row (starts at 0). Quotient bits read top→bottom: Q₃Q₂Q₁Q₀.

Quotient bits Q₃Q₂Q₁Q₀ = 0010₂; final remainder R′ = 0000₂.

Q = 0010₂ = 2  ·  remainder = 0  ·  check: 2 × 7 + 0 = 14 ✓
Final answer · 14 / 7
Quotient = 2  ·  Remainder = 0
الفكرة (نفس طريقة الدكتور في السلايد). كل خطوة: نزحزح الباقي شمال وندخّل بتّ جديد من المقسوم، وبعدين نطرح المقسوم‌عليه D = R − B. لو D سالب يبقى الـ 7 مدخلش → البتّ = 0 ونرجّع الباقي زي ما هو (R′ = R)؛ لو D موجب أو صفر يبقى دخل → البتّ = 1 والباقي الجديد = D. الناتج Q = 0010 = 2 والباقي 0. أهم نقطة: عمود D هو ناتج الطرح (R − B)، مش المقسوم‌عليه.

QUESTION 04

Fill the ALU function table

datapath · ALU
Question 4 — exam paper · نفس ورقة الدكتور بالظبط
الحل · Solution

In the course ALU the control splits in two: F2 chooses B (0) or B̄ (1) and sets the adder’s carry-in for subtraction, while F1:0 picks which result the output multiplexer passes — 00 → AND, 01 → OR, 10 → the adder, 11 → SLT.

F2:0FunctionHow the ALU does it
000A AND Boutput mux selects the AND unit
001A OR Boutput mux selects the OR unit
010A + Badder, carry-in = 0
011not used—
100A AND B̄F2 inverts B, then AND
101A OR B̄F2 inverts B, then OR
110A − Badder computes A + B̄ + 1
111SLTSet Less Than: 1 if A < B, else 0
↳

Why subtraction reuses the adder. Setting F2 = 1 feeds B̄ into the adder and forces carry-in = 1, so it computes A + B̄ + 1 = A − B in two’s complement. No separate subtractor is needed.

Why SLT “just works”. SLT subtracts (A − B) and looks at the sign bit of the result: if the result is negative then A < B, so the ALU outputs 1; otherwise 0.

الفكرة. الـ F2 هو مفتاح "اقلب B واطرح"، والـ F1:0 بيختار المخرج (AND / OR / الجامع / SLT). عشان كده الطرح بيستعمل نفس الجامع بتاع الجمع (A + B̄ + 1)، والـ SLT بيبص على إشارة ناتج الطرح.

QUESTION 06

2:1 Multiplexer

combinational · MUX
From the doctor’s slide Design a 2:1 multiplexer with data inputs D0, D1 and select line S. Give the truth table and the Boolean equation of the output Y.
الحل · Solution

A multiplexer forwards one of its inputs to the output, chosen by the select line: S = 0 passes D0, and S = 1 passes D1.

SD1D0Ywhy
0000S=0 → Y=D0=0
0011S=0 → Y=D0=1
0100S=0 → Y=D0=0
0111S=0 → Y=D0=1
1000S=1 → Y=D1=0
1010S=1 → Y=D1=0
1101S=1 → Y=D1=1
1111S=1 → Y=D1=1

Collapsing the table: when S = 0 the output equals D0; when S = 1 it equals D1. So

Final answer · 2:1 MUX
Y = S̄ · D0 + S · D1
الفكرة. الـ MUX زي مفتاح: الـ S بيختار مين يعدّي للخرج — S=0 يعدّي D0، وS=1 يعدّي D1. المعادلة Y = S̄·D0 + S·D1. بيتبني من عاكس + بوابتين AND + بوابة OR.

QUESTION 07

Shifters — and multiply / divide by 2N

arithmetic · shifters
From the doctor’s slides Evaluate the following shifts of the 5-bit value 11001, then show how a shift multiplies or divides by a power of two.
الحل · Solution

Shift types. A logical shift fills the empty places with 0. An arithmetic right shift fills them with the old sign bit (msb) so the sign is kept. A rotate wraps bits around.

Operation on 11001Resultfills with
11001 >> 2  (logical right)001100
11001 << 2  (logical left)001000
11001 >>> 2 (arithmetic right)11110msb = 1
11001 ROR 2 (rotate right)01110wrap
11001 ROL 2 (rotate left)00111wrap

Shifting = multiply / divide by a power of two

Left shift by N multiplies by 2N; arithmetic right shift by N divides by 2N (5-bit two’s complement):

RuleExamplemeaning
A << N = A × 2N00001 << 2 = 001001 × 4 = 4
A << N = A × 2N11101 << 2 = 10100−3 × 4 = −12
A >>> N = A ÷ 2N01000 >>> 2 = 000108 ÷ 4 = 2
A >>> N = A ÷ 2N10000 >>> 2 = 11100−16 ÷ 4 = −4
Key result
Left-shift ×2N · arithmetic right-shift ÷2N — no multiplier/divider needed for powers of two.
الفكرة. الإزاحة شمال بـ N = ضرب في 2N، والإزاحة يمين الحسابية بـ N = قسمة على 2N (وبتحافظ على الإشارة لأنها بتملا بالـ msb القديم). ده أرخص بكتير من دائرة ضرب/قسمة كاملة لما يكون العدد قوة للـ 2.

QUESTION 08

Set-Less-Than on the 32-bit ALU

datapath · SLT · 32-bit
From the doctor’s slide Configure the 32-bit ALU for the SLT (set-less-than) operation with A = 25 and B = 32. What does Y become, and why?
الحل · Solution
1

Pick the control. SLT is F2:0 = 111 (from the ALU table in Q4).

2

F2 = 1 makes the adder subtract. It computes A − B = 25 − 32 = −7.

3

Look at the sign bit. −7 in two’s complement has a 1 in the most-significant bit (S31 = 1), which means the result is negative → A < B.

4

F1:0 = 11 selects S31, zero-extended. So the output is a 32-bit 1.

Final answer · SLT(25, 32)
Y = 0x0000 0001   (because 25 < 32, SLT returns 1)
الفكرة. الـ SLT بيطرح A − B ويبص على بت الإشارة (S31): لو الناتج سالب يبقى A أصغر من B فالخرج = 1، وإلا 0. هنا 25 − 32 = −7 (سالب) → A < B → Y = 1. الـ F2=1 خلّى الجامع يطرح، والـ mux اختار بت الإشارة موسّع بالأصفار.

QUESTION 09

IEEE-754 single-precision

number systems · floating point
From the doctor’s slide Represent the value 228 in 32-bit IEEE-754 floating-point format. Give the sign, biased exponent, fraction, and the final hexadecimal.
الحل · Solution

Single precision = 1 sign bit · 8 exponent bits · 23 fraction bits, with exponent bias = 127.

1

Decimal → binary. 228 = 11100100₂.

2

Binary scientific notation (float the point after the leading 1): 11100100 = 1.11001 × 27.

3

Fill the fields. Sign = 0 (positive). Biased exponent = 127 + 7 = 134 = 10000110₂. Fraction = the bits after the leading 1 (which is implicit, not stored) = 110 0100 0000 0000 0000 0000.

Sign (1)Biased exponent (8)Fraction (23)
010000110110 0100 0000 0000 0000 0000
0100 0011 0110 0100 0000 0000 0000 0000 = 0x43640000
Final answer · 228 in IEEE-754
0 · 10000110 · 1100100… = 0x43640000
الفكرة (طريقة الدكتور). حوّل لـ binary → اكتبه 1.f × 2E → الإشارة (0 موجب) + الأس المتحيّز (127 + E) + الكسر (البتات بعد الـ 1 الضمنية). الـ 1 اللي قبل الفاصلة مبتتخزنش. طلع 0x43640000. نفس الخطوات تشتغل لأي رقم (مثال الدكتور التاني: −58.25 = 0xC2690000).

Memory array & the register file

memory · register file

An N-address, M-bit array has 2N rows (depth = words) and M columns (width = word size). Here N = 2, M = 3 → 4 words × 3 bits. A 2:4 decoder raises exactly one wordline (the address); that row’s stored bits drive the bitlines out as Data.
